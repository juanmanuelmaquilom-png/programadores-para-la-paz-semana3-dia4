Responde con tus propias palabras.

1. ¿Qué es un array en JavaScript?

Respuesta: Es una estructura que permite guardar varios datos dentro de una sola variable, como una lista.

2. ¿Para qué sirve guardar varios datos en un array?

Respuesta: Sirve para organizar información y poder trabajar con muchos datos de forma más fácil y rápida.

3. ¿Qué tipo de información comunitaria podría guardarse en un array?

Respuesta: Nombres de personas, direcciones, números de contacto, eventos del barrio o reportes de problemas.

4. ¿Qué hace un for tradicional?

Respuesta: Permite repetir un bloque de código varias veces según una condición.

5. ¿Qué representa la variable i en un for tradicional?

Respuesta: Es un contador que indica en qué posición del ciclo va el programa.

6. ¿Qué significa .length?

Respuesta: Indica la cantidad de elementos que tiene un array.

7. ¿Qué hace for...of?

Respuesta: Recorre directamente los elementos de un array sin necesidad de usar índices.

8. ¿Qué diferencia inicial encuentras entre for y for...of?

Respuesta:El for usa un contador e índices, mientras que for...of accede directamente a los valores del array.

9. ¿Qué hace el comando npm run revisar?

Respuesta: Ejecuta un script configurado en el proyecto para revisar o validar el código.

10. ¿Cómo puede ayudar un array organizado a la participación ciudadana?

Respuesta: Permite tener la información ordenada, facilitando el acceso, análisis y toma de decisiones en la comunidad.
